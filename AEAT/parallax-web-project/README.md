# Parallax Web Project

Este proyecto implementa un efecto de parallax en la cabecera de una página web. El efecto parallax crea una ilusión de profundidad al hacer que el fondo se desplace a una velocidad diferente que el contenido en primer plano, lo que resulta en una experiencia visual atractiva.

## Estructura del Proyecto

El proyecto contiene los siguientes archivos:

- **index.html**: Este archivo es la estructura principal de la página web. Contiene la cabecera y el contenido principal, así como la referencia a los archivos CSS y JavaScript necesarios para implementar el efecto parallax.

- **css/styles.css**: Este archivo contiene los estilos CSS para la página. Incluye estilos para la cabecera, el efecto parallax y otros elementos de la interfaz.

- **images/background.jpg**: Esta imagen se utiliza como fondo para el efecto parallax en la cabecera.

- **js/parallax.js**: Este archivo contiene el código JavaScript que implementa la lógica del efecto parallax. Escucha el evento de desplazamiento y ajusta la posición del fondo en función de la posición de desplazamiento del usuario.

## Instrucciones de Configuración

1. **Clonar el Repositorio**: Clona este repositorio en tu máquina local usando el siguiente comando:
   ```
   git clone <URL del repositorio>
   ```

2. **Abrir el Proyecto**: Navega a la carpeta del proyecto:
   ```
   cd parallax-web-project
   ```

3. **Abrir el Archivo HTML**: Abre el archivo `index.html` en tu navegador para ver el efecto parallax en acción.

## Cómo Funciona el Efecto Parallax

El efecto parallax se logra mediante el uso de CSS para establecer la imagen de fondo y JavaScript para ajustar su posición en función del desplazamiento del usuario. A medida que el usuario se desplaza hacia abajo en la página, el fondo se mueve a una velocidad diferente que el contenido en primer plano, creando una sensación de profundidad.
